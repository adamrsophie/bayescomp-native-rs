# bayescompRCranelift 0.1.0

* First release: the `"cranelift"` backend for 'bayescompR' computes the log
  density and its gradient in machine code generated by Cranelift, with the
  reference interpreter of the shared runtime as a second engine.
* The Rust dependencies are vendored in `src/rust/vendor.tar.xz` and built
  offline with at most two jobs.
